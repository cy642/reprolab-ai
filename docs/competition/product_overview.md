# ReproLab AI · 研途复现官

ReproLab AI 面向需要复现实验的学生、研究人员和课题组。它把论文原文、参数来源、数据切分审计、指标和审批记录汇集到一份可核验的报告。评审可以从结论回到具体证据，也能看到哪些参数仍待确认。

## 技术架构

| 模块 | 输入与产出 |
| --- | --- |
| Paper Intelligence | PyMuPDF 提取 PDF 文本，输出结构化字段和页码级引文。启用模型时可补充提取，待确认字段在界面保留。 |
| Protocol Builder | 根据论文证据生成可编辑的步骤 DAG 和参数表，保留原值、人工修改、版本以及参数来源。 |
| Data Guardian | Python 规则检查跨切分实体重叠、重复、缺失、类别分布、异常特征和切分覆盖，并定位到记录。 |
| Experiment Insight | Python 计算对比、混淆矩阵、稳定性和消融。模型可以补充叙述和建议，计算结果和数据风险以结构化输出为准。 |
| 工作流与报告 | FastAPI 编排各模块。SQLite 保存执行状态、输入快照、人工审批和日志。React 提供操作界面并展示定稿。 |

## 答辩重点

- **证据先行。** 参数可追溯到 PDF 的页码与引文。证据定位后的语义核对仍由读者完成，无法核实的参数继续标为待确认。
- **风险贯穿流程。** 跨 Train/Test 的患者重叠能定位到 CSV 行。选择继续分析后，报告同时展示已知悉风险、未通过审计和仍未解决的发现。
- **可追溯的交付。** 工作流到达报告节点后保留来源、执行方式和统计限制。定稿后编辑上游方案，旧报告导出保持原样。
- **执行方式可查。** 模型请求、响应、回退和历史复用分别记录。比赛离线演示可以核查规则路径，真实模型的验证结果另有记录。

## 使用边界

演示 CSV 和指标为合成输入，展示的是审计、统计和复现准备。流程不运行训练作业。均值区间与观察差值不能单独证明方法差异显著。报告导出发生在本地。
